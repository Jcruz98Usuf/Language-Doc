# Local speech-to-text benchmark (Phase 7A)

Measures the **local, offline** speech-to-text engine that replaces the browser's
cloud-based `SpeechRecognition` on the host laptop. Nothing here contacts a cloud
service: the speech audio is generated by the Windows voices already installed on
the machine, and the models run in-process.

## How to run

```powershell
npm run bench:stt:audio      # generate the speech clips locally (Windows SAPI, 16 kHz mono)
npm run bench:stt            # benchmark tiny.en and base.en against them
STT_BENCH_MODELS=tiny.en npm run bench:stt                 # one model only
```

Audio lands in `benchmarks/stt/audio/`, reports in `benchmarks/stt/results/<timestamp>/report.md`.
Both directories are git-ignored: the audio is locally generated and the report is
regenerated on demand.

## Candidates and licences

| Model (ONNX export) | Upstream | Role | Disk | Licence |
|---|---|---|---|---|
| `Xenova/whisper-tiny.en` | `openai/whisper` | English, default | ~41 MB | MIT ✅ |
| `Xenova/whisper-base.en` | `openai/whisper` | English, larger | ~78 MB | MIT ✅ |
| `Xenova/whisper-tiny` | `openai/whisper` | multilingual (French/Swahili) | ~41 MB | MIT ✅ |
| `Xenova/whisper-base` | `openai/whisper` | multilingual, larger | ~78 MB | MIT ✅ |

Runtime: `@huggingface/transformers` (Apache-2.0) on `onnxruntime-node` (MIT).
The multilingual checkpoints are used when the *non-English* mic panel is used
(French/Swahili). Luganda, Kinyarwanda, Somali, Luo, Kikuyu and Kalenjin are **not**
in Whisper's language set, so local STT refuses them instead of guessing.

An alternative engine was investigated but not adopted: **whisper.cpp** as an HTTP
sidecar (`src/server/services/stt/whisperCppProvider.ts`). whisper.cpp is MIT and
its GGML weights are MIT, so the licence is fine — but this machine has no
whisper.cpp binary, and the in-process ONNX path needs no extra binary at all.
The sidecar contract is implemented and can be enabled with `STT_PROVIDER=whisper-cpp`
plus `STT_SIDECAR_URL`, which makes trying it later a configuration change rather
than a code change.

## Method

- 14 English sentences across clinic, hotel, office and general conversation,
  chosen to include the risky cases: symptoms, negation, medication names, dosage,
  numbers, dates, booking duration, room numbers, meeting dates, action items, names.
- The reference transcript is the sentence that was spoken, so scoring is pure
  recognition error (word error rate: substitutions + insertions + deletions).
- `cold` latency is the first clip of a run (includes the one-time ONNX session
  load); `warm` is the mean of the remaining clips. RTF = latency / audio length.
- Failure modes are recorded explicitly: empty output, repetition, and errors.

## Chosen default: `base.en`

Both sizes were measured (see `results/`). Mean WER came out almost identical
(11.3% tiny.en vs 11.5% base.en) because most of the "errors" are number-format
differences that are semantically correct (`three hundred and five` -> `305`,
`ninety dollars` -> `$90`). Human review of the transcripts decided it:

| Risky item | tiny.en | base.en |
|---|---|---|
| Date year ("two thousand and twenty six") | ❌ **"2021"** | ✅ "2026" |
| Drug name ("amoxicillin") | ⚠️ split as "a moxacillin" | ✅ "amoxicillin" |
| Drug name ("paracetamol") | ❌ "perisetimal" | ⚠️ "parasetimal" |
| Warm latency | 1704 ms (RTF 0.36) | 3001 ms (RTF 0.63) |

`base.en` is the default because a wrong **year** or a wrong **drug name** in a
clinic outweighs 1.3 s of latency. Neither size is reliable enough to be trusted
blindly for medication names: the transcript stays editable and typed input
remains the authoritative path. Set `STT_WHISPER_MODEL_EN=tiny.en` when latency
matters more than number fidelity.

## Do not over-claim

Synthesised speech is cleaner than human speech in a noisy clinic or lobby, and no
French or Swahili voice is installed on this machine, so the multilingual path is
plumbed but **not** measured here. Passing this benchmark is not a statement of
medical accuracy; real transcripts still need human review.
